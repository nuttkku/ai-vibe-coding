# 🤖 AI Vibe Coding

หลักสูตรสร้างแอปด้วย AI โดย Wanut Padee (wanut@kku.ac.th) แบ่ง 2 ระดับ เลือกตามพื้นฐานผู้เรียน

| ระดับ | หลักสูตร | เหมาะกับ | เนื้อหา |
|---|---|---|---|
| 🌱 เริ่มต้น | [Vibe Coding for Beginners](beginners/) | คนที่ไม่เคยเขียนโค้ด | 8 labs: ติดตั้ง → คุยกับ AI → prompt → หน้าเว็บแรก → Git Desktop → Docker → แอปรับ feedback → debug/rollback |
| 🚀 ต่อยอด | [AI Vibe Coding ด้วย Claude (5 วัน)](claude-code-course/) | คนที่พอมีพื้นฐาน อยากทำเว็บแอปจริงจนขึ้น production | Claude Code: scaffold → UI/API/DB → testing → security scan → CI/CD → deploy → demo |

แนะนำให้เรียนระดับเริ่มต้นก่อน ถ้ายังไม่คุ้นกับ terminal และ Git
